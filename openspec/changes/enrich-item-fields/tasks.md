## 3. 어댑터 확장

- [x] 3.1 `schema.ts`의 행 스키마에 확장 필드를 **전부 optional로** 추가 — required로 만들면 소스가 하나만 안 보내도 회차 전체가 죽는다(design D6)
- [x] 3.2 `adapter.ts`의 정규화 변환에 확장 필드 매핑을 추가. 값 없음 처리는 design D3 규칙대로 필드별로 적용하고, 코드값은 해석 없이 원문 보존(D4)
- [x] 3.3 실제 응답 fixture(`REAL_ROW` 등)로 확장 필드가 정확히 매핑되는 것을 테스트 — 네트워크 요청 금지
- [x] 3.4 확장 필드가 전부 비어 있는 행에서도 물건이 정상 수집되고 기존 필드 처리에 영향이 없는 것을 테스트
- [x] 3.5 "행은 왔는데 확장 필드가 전부 비었다"는 경우 필드명 변경 의심 경고를 남기고, 그 경고가 회차를 죽이지 않는 것을 테스트
- [x] 3.6 **회귀**: 기존 어댑터 테스트가 전부 그대로 통과하는 것과, `AuctionSource` 계약(`{items, pagesRequested}`)이 바뀌지 않은 것을 확인
