## MODIFIED Requirements

### Requirement: 분석 대상 선정
분석 워커는 분석이 필요한 물건을 조회해 분석 대상으로 삼아야 한다(SHALL). 분석이 필요한 물건은 다음 세 가지다:

1. 분석 결과가 아직 없는 물건
2. 최신 분석 이후 감시 대상 필드가 변경된 물건 — 최저가가 떨어진 뒤에도 옛 가격 기준 분석이 남아 있으면 틀린 정보가 되기 때문이다
3. 최신 분석이 워커의 현재 프롬프트 버전보다 낡은 버전으로 생성된 물건

한 실행 회차에서 처리할 최대 물건 수는 설정으로 제한할 수 있어야 한다(SHALL) — 분석 비용(Claude 호출 수)을 통제하기 위함이다. 신규 분석과 재분석의 회차당 건수는 각각 제한할 수 있어야 하며(SHALL), 신규 물건 분석이 재분석보다 우선해야 한다(SHALL) — 아직 한 번도 분석되지 않은 물건이 재분석 대기열에 밀려 무한히 미뤄져서는 안 된다(MUST NOT).

기존 `analyzed` 필터의 의미(분석 결과 유무)는 바뀌지 않아야 하며(MUST NOT), 재분석 대상 조회는 별도 수단으로 제공되어야 한다(SHALL).

#### Scenario: 미분석 물건 선정
- **WHEN** 분석 워커가 실행되면
- **THEN** 미분석 물건이 회차당 최대 건수 이내로 조회되어 순차 분석된다

#### Scenario: 분석할 물건이 없는 경우
- **WHEN** 미분석 물건이 없고 재분석 대상도 없는 상태에서 워커가 실행되면
- **THEN** 아무 분석도 실행하지 않고 정상 종료한다

#### Scenario: 변경된 물건 재분석
- **WHEN** 이미 분석된 물건의 최저매각가격이 변경된 뒤 워커가 실행되면
- **THEN** 그 물건이 재분석 대상으로 선정되어 다시 분석된다

#### Scenario: 프롬프트 버전 갱신에 따른 재분석
- **WHEN** 워커의 프롬프트 버전이 저장된 분석의 버전보다 새로운 상태에서 워커가 실행되면
- **THEN** 그 물건이 재분석 대상으로 선정된다

#### Scenario: 변경 없고 버전도 같은 물건
- **WHEN** 이미 분석되었고 이후 변경이 없으며 프롬프트 버전도 동일한 물건만 있는 상태에서 워커가 실행되면
- **THEN** 그 물건은 재분석되지 않는다

#### Scenario: 신규 분석이 재분석에 밀리지 않음
- **WHEN** 재분석 대상이 신규 한도보다 훨씬 많은 상태에서 미분석 물건도 함께 있으면
- **THEN** 미분석 물건이 먼저 신규 한도만큼 배정되고, 재분석은 자신의 별도 한도 안에서만 처리되어 미분석 물건이 뒤로 밀리지 않는다

#### Scenario: 기존 analyzed 필터 의미 유지
- **WHEN** 클라이언트가 `analyzed=false`로 목록을 조회하면
- **THEN** 재분석 대상 여부와 무관하게 분석 결과가 하나도 없는 물건만 반환된다

### Requirement: 분석 결과 표시
물건 상세 페이지는 해당 물건의 최신 분석 결과를 표시해야 한다(SHALL). 분석 결과가 아직 없으면 "분석 대기 중"임을 안내해야 한다(SHALL).

같은 물건에 분석이 여러 건 있으면 최신 것을 기본으로 표시하고, 이전 분석도 열람할 수 있어야 한다(SHALL). 각 분석에는 분석 시각과 프롬프트 버전이 함께 표시되어야 한다(SHALL). 재분석은 이전 분석을 삭제해서는 안 된다(MUST NOT).

#### Scenario: 분석 완료 물건 상세
- **WHEN** 분석 결과가 저장된 물건의 상세 페이지를 열면
- **THEN** 분석 요약과 분석 시각이 물건 정보와 함께 표시된다

#### Scenario: 분석 전 물건 상세
- **WHEN** 아직 분석되지 않은 물건의 상세 페이지를 열면
- **THEN** 물건 정보는 정상 표시되고 분석 영역에는 대기 중 안내가 표시된다

#### Scenario: 재분석된 물건 상세
- **WHEN** 분석이 2건 이상 있는 물건의 상세 페이지를 열면
- **THEN** 최신 분석이 기본으로 표시되고, 이전 분석이 몇 건 있는지와 그 내용을 볼 수 있는 수단이 제공된다

#### Scenario: 이전 분석 보존
- **WHEN** 이미 분석된 물건이 재분석되면
- **THEN** 새 분석이 추가되고 이전 분석은 삭제되지 않는다
