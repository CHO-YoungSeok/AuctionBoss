## 0. 공통 — 필터 추가 체크리스트

새 필터 파라미터마다 **여섯 곳을 전부** 고친다. 하나라도 빠지면 조용히 틀린다.

1. `ITEM_QUERY_PARAMS` — 빠지면 파서가 무시하고 아무 일도 안 일어난다
2. zod 스키마(strict/lenient 양쪽)
3. `ItemQuery` 타입과 변환
4. **`hasActiveFilters`** — 빠지면 필터로 0건일 때 "DB가 비었다"는 거짓 안내가 뜬다
5. `buildFilter` — `where`가 `total` 카운트에도 쓰인다
6. `itemQuerySearchParams` — 빠지면 페이지 이동 시 필터가 사라진다

- [x] 0.1 필터마다 **"이 필터로 0건일 때 올바른 안내와 초기화 링크가 나오는가"** 테스트를 반드시 추가할 것. `hasActiveFilters` 누락을 잡는 유일한 방어선이다
- [x] 0.2 필터마다 **"페이지 이동 후에도 조건이 유지되는가"** 테스트를 추가할 것
